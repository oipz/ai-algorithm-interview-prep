# AI 算法岗面试题库

手机端可快速刷题、做题、记忆的 **纯静态** 面试题库站点。无后端、无外部依赖、离线可用，所有进度与记忆标记保存在浏览器 `localStorage`。

> 真题优先（为主，覆盖 AI 岗），缺失考点按常见考点自出并标注。站点已****，不含任何，专有名词已。

## 在线访问

GitHub Pages：https://oipz.github.io/ai-algorithm-interview-prep/

## 站点结构

```
├── index.html              # 落地页 + 顶部 sticky 四档导航（学习 / 刷题 / 选择题 / 问答）
├── learn.html              # 学习板块：11 个算法专题讲解（自编，来源注明），学完跳对应专题刷题
├── algorithm.html          # 算法刷题区（v2：单题视图 + 三级提示 + 侧边栏 + 答过状态，离线自包含）
├── ai-section.html         # AI 知识区（闯关选择题 + 问答浏览，自包含）
├── algorithm-problems.json # 算法题结构化数据（含三级提示，便于复用）
└── assets/
    ├── site.css            # 共享站点样式（落地页 + 顶部导航 + 卡片）
    └── site.js             # 共享脚本（导航高亮 + 统一 localStorage 命名空间）
```

顶部 sticky 导航在「📚 学习 / 🧮 刷题 / 📝 选择题 / 💬 问答」四档间切换；各区子页面顶部「首页」回到 `index.html`。

## v2 刷题区特性

- 🎯 **单题视图**：每次只显示一道题，默认只看题面，点击才展开题解与代码。
- 🔢 **编号与跳转**：每题编号（1–102），可按编号跳转，顶部显示覆盖进度。
- 🎲 **多种推进**：顺序刷 / 随机刷 / 按专题刷 / 全部随机，可切换。
- 💡 **三级递进提示**：每题 3 条提示，从「很粗糙」到「比较具体」逐级展开，每条只点一个点；题面上方不显示任何 tag 或解法提示。
- 💻 **代码语法高亮**：内联轻量 C++ 高亮，离线可用。
- 📑 **可伸缩侧边栏**：列出全部题目与状态（看过 / 未看 / 完成 / 收藏），点击跳转、支持搜索。
- ✅ **答过状态 + 筛选**：看过 / 未看过 / 已完成 / 未完成 / 收藏多档筛选，状态存 `localStorage`。
- 🎨 **统一深色风格**：与 AI 知识区一致的深色渐变 + 玻璃卡片 + 青色点缀。

## 特性

- 📱 手机优先：内容列宽 ≤480px，竖向单列浏览。
- 💾 本地存储：进度与记忆标记存于浏览器 `localStorage`，清除浏览器数据会丢失。
- 🔌 离线可用：纯静态，无构建步骤，浏览器直接打开即用。
- 🎨 闯关即时反馈：选择题作答后即时判分（对✅绿 / 错❌红）并展示解析。

## 本地预览

直接用浏览器打开 `index.html` 即可；或任起一静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000/
```
